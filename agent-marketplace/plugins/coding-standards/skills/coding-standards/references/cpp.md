These rules extend the global instructions.

## C++ formatting

- Treat `#include` directives and C++ module imports as the contiguous import block.
- Leave a blank line between consecutive structs, classes, functions and type aliases, at namespace and class scope,
  so each declaration and its documentation comment stands apart.

## C++ documentation

- Use Doxygen syntax when the project uses Doxygen.

## C++ language

- Names imposed by the standard library are exempt from the British English rule.

## C++ tooling

- Run `clang-format` as the formatter, using the project's configuration.
