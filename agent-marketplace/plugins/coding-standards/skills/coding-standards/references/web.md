These rules extend the global instructions.

## Web documentation

- Use a one-line JSDoc or TSDoc description for every function, method, class and UI component.
- Use the appropriate comment syntax for JavaScript, TypeScript, markup and styles.

## Web language

- Names imposed by web standards or third-party APIs (e.g. CSS `color`) are exempt from the British English rule.

## Web testing

- Examples: `geometry_test.ts`, `viewer_test.tsx`.

## Web tooling

- Run the project's configured formatter (e.g. Prettier when configured).
